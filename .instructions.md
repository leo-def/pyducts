# Development Instructions for Pyducts (BRDD)

> Guidelines for BRDD development in Pyducts using FastAPI and Python.

## 🎯 Project Overview

- **Type**: BRDD reference implementation
- **Framework**: FastAPI, SQLAlchemy
- **Pattern**: Business Rule Driven Design
- **Documentation**: Every rule has a B-code in BUSINESS_CONTEXT.md

---

## 🤖 Instructions for AI Agents

### ✅ DO's
1. **Always link to B-codes** - Every validation maps to BUSINESS_CONTEXT.md
2. **Use ExecutionContext** - Return context, never raw JSON
3. **Document in BUSINESS_CONTEXT.md** - Before implementing, add B-code
4. **Handle effects properly** - Track all side effects (emails, logs, state changes)
5. **Test with ExecutionContext** - Verify codes and effects are recorded

### ❌ DON'Ts
1. **Don't hardcode error messages** - Link to B-code instead
2. **Don't return raw JSON** - Always use ResponseService.construct_response
3. **Don't create side effects silently** - Record in ExecutionContext
4. **Don't ignore BUSINESS_CONTEXT.md** - It's the source of truth
